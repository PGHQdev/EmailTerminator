## Question

What does CI build, on what runners, and what does a tag produce?

Axes:

- Platform matrix and its cost. macOS first, Linux second, Windows when

- Cross-compilation versus native runners for each target.
- What a tagged release does end to end: build every artifact from 16,
  publish to npm, publish the installer, cut the GitHub release.
- Validation of the community data files from 14 on every pull request.
- Whether any secret is needed, and what an unsigned release avoids.
