## Question

Split from the original ticket 17 on 2026-08-10. Release automation moved to

Axes:

  second, Windows when cheap (`CONTEXT.md`) — this ticket decides what "cheap"
  means for checks, not for releases.
- Which runners: GitHub-hosted, and whether macOS arm64 minutes are affordable
  on a public repository.
- Rust checks: build, test, clippy, fmt, and whether the 10 GB scan tolerance
  from ADR 0001 is enforced anywhere automatically.
- UI checks: type generation drift (ticket 20), lint, and the design-system
  adherence config at `docs/reference/design/_ds/organic-*/_adherence.oxlintrc.json`.
- Validation of the community data files from 14 on every pull request.
- Caching, and what an external contributor's first pull request costs in
  minutes.
