EmailTerminator — v0 screens
All 12 app screens + landing page, light and dark, on the Organic system with Bricolage Grotesque headings. Direction from the picked candidate: bubbles = money (dashboard, with a bubble/table toggle on Subscriptions), rows = work everywhere else. Navigation is a left icon rail (short labels) with a context-aware action button pinned at its foot, plus a ⌘K command palette as accelerator. Dark theme is espresso (warm neutrals; green survives only as status dots). Money details set in monospace, receipt-style. Critical services get a prominent blocking confirm. Kill animation (spec): on unsubscribe/cancel success the row or bubble deflates with a spring, pops into a small "✓ saved $X" pill that flies to the rail's action button, and the hero totals count down.
